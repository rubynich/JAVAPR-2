# Практическая работа №12
Stream API, Comparator, Optional и функциональная обработка коллекций


Запуск в Windows: дважды нажмите run_selfcheck.bat.
Проверки запускаются в ru.edu.pr09.SelfCheck.

Исходный список не изменяется. topSales использует filter, sorted и limit;
maxSale возвращает Optional; totalsByManager группирует суммы по менеджерам;
сортировка использует Comparator по сумме (по убыванию) и id (по возрастанию).

Для варианта 6 принято явное рабочее правило: дополнительный агрегат считает
количество продаж с суммой не менее 35.0. В методичке дан параметр 35
