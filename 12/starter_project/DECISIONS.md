# DECISIONS

1. Stream API используется для фильтрации, преобразования, сортировки и агрегирования. Потоковые операции не изменяют исходный список; для результата создаётся новая коллекция или Map.
2. Для варианта 6 реализован дополнительный агрегат countSalesAtLeast35: он считает продажи с суммой не менее 35.0. Это рабочее толкование параметра 35, поскольку методичка не раскрывает точную формулу дополнительного агрегата. Если преподаватель дал уточнение, условие следует заменить в одном методе.
