# DECISIONS

1. Для чтения выбран Files.newBufferedReader вместе с try-with-resources: файл читается построчно, а ресурс закрывается автоматически даже при исключении.
2. Ошибки открытия файла и ошибки отдельной строки разделены: IOException выходит из importFile, а IllegalArgumentException конкретной записи превращается в ImportError и не прерывает цикл.

Допущение по индивидуальной части: повторный ИНН отклоняется, уже сохранённая запись не перезаписывается. В тексте задания для варианта 6 указан параметр 35.
